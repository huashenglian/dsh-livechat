# 礼物特效

[English](./gift-effects.md) | [中文](./gift-effects.zh-CN.md)


观众礼物模拟：把礼物动画叠在对话区上，并飘出一条送礼提示弹幕。总开关默认关闭，绑定素材后才生效。

## 总览

礼物特效由三层组成：

- **素材仓库**——本地素材库（SVG / SVGA / 图片），带文件夹、权重与 manifest，落在 `$DSH_HOME/danmaku-gifts/`。
- **礼物目录**——B 站礼物清单（名称 / ID / 价格 / 图标），用于左列选择；内置一份离线目录，也可用你自己的房间号刷新。
- **绑定与特效**——把「礼物」绑到「素材」，设置落点、缩放、时长、循环；触发时播放动画并叠加一条提示弹幕。

礼物特效与弹幕渲染共用同一覆盖层：特效在独立的 `.dsh-gift-layer` 上播放，不拦截鼠标事件；提示弹幕走普通弹幕轨道。

## 入口

设置 → 插件 → 插件配置 →「弹幕 Live Chat」卡片，滚到 **礼物** 区段：

- **启用礼物特效**（`giftEnabled`）——总开关，**默认关闭**。
- **打开礼物配置…**——打开大模态并定位到绑定段。
- **素材仓库…**——打开大模态并定位到素材段。

也可在设置左侧导航点「礼物」Tab（紧跟在「弹幕库」之后）。大模态 `min(960px, 94vw)` × `min(680px, 86vh)`：左列是礼物清单（搜索名称/ID、按 `coin_type`/`type` 过滤、首批 100 行 +「加载更多」、图标 404 占位、「未绑定」标记）；右区是**单页三段**——素材仓库 / 绑定与特效参数 / 送礼模拟——配右侧细锚点条，不来回切菜单。

## 素材格式与导入

支持的扩展名：`.svg`、`.svga`、`.gif`、`.apng`、`.webp`、`.png`、`.jpg`。单文件大小上限 `giftMaxAssetMB`（默认 8 MB，可调 1–64）。

素材仓库工具条提供四种导入方式：

| 方式 | 说明 |
|---|---|
| 选择文件 | 多选本地文件，逐个入库 |
| 粘贴 SVG 代码 | 直接粘贴 SVG 源码；**Host 先清洗**（`sanitizeSvg`）再入库，白名单外的容器/脚本被丢弃 |
| GitHub 导入… | 填 git 仓库地址（`https` / `git@` / `file://`），克隆后导入仓库内素材 |
| zip 上传 | 上传压缩包，**解压前逐条校验入口名**（拒绝 `..` 越界），以任务方式导入并带进度/中止 |

导入是**任务制**：上传接口返回任务对象，前端轮询 `/api/danmaku/gift/assets/import/status` 显示进度。素材文件落在 `$DSH_HOME/danmaku-gifts/files/`，清单为同目录 `manifest.json`；服务走 `GET /api/danmaku/gift/file?id=`（支持 Range / ETag / immutable 缓存）。

> [!NOTE]
> 礼物素材是**用户资产**：卸载插件时不会自动删除；「清空素材」按钮需二次确认。

## 目录与刷新

礼物清单默认读 `$DSH_HOME/danmaku-gifts/catalog.json`；不存在时从包内 `assets/gift-catalog.json` 播种一份（离线可用）。

要刷新为**你自己的**房间礼物清单：

1. 在配置里填 `giftRoomId`——**房间号由你本人填写**，仓库与文档里一律用占位符，例如 `<你的房间号>`。
2. 点「刷新目录」，等价于 `POST /api/danmaku/gift/catalog` `{"action":"refresh"}`。

行为约定：

- **房间号为空 → 不发起任何外部请求**，直接回内置目录（`reason: "no-room"`），且不写任何文件。
- 刷新成功 → 用实时礼物配置映射出清单，原子写入 `catalog.json`。
- 刷新失败 → 静默降级回内置目录（`reason: "fetch-failed"`），不弹错误、不打断使用。
- 映射只读白名单字段，原始响应里的房间标识（`room_id` / `uid` 等）**不会**进入清单。

## 绑定与特效参数

在左列选中一个礼物后，右区「绑定与特效参数」段可：

- **绑定素材**——缩略网格小弹层里选一个素材；未绑定显示空态引导。
- **位置**——`center` / `top` / `bottom` / `top-left` / `top-right` / `bottom-left` / `bottom-right` / `random` 共 8 个选项（7 个预设点位 + 随机）。
- **缩放**——0.25–2 倍；实际尺寸 = `min(视口宽, 视口高) × 0.5 × 缩放`，裁剪到 0.25–2。
- **时长**——1–10 秒。
- **循环**——勾选后时长到点仍循环播放，直到被替换/清理。
- **位置预览条**——小画框按归一化锚点显示落点，随下拉实时变化。
- **解除绑定** / **重置绑定**——单个解绑，或一次清空全部 `giftBindings`。

绑定写入 `giftBindings`，以礼物 id 为键：`{assetId, position, scale, durationMs, loop}`。

## 送礼模拟

右区「送礼模拟」段（总开关关闭时提示「先开启礼物模块」并禁用）：

- **手动触发**（`giftTrigger.manual`）——默认开。
- **随机环境触发**（`giftTrigger.random`）——默认关；开启后按 `probability`（0–1）与 `minMs`/`maxMs` 间隔（1 秒–1 小时）参与抽签。
- **提示模板**（`giftTemplate`）——占位符 `{user}` 送礼人、`{gift}` 礼物名，最长 100 字符，输入时实时预览替换结果。
- **送礼人池**（`giftSenders`）——`{name, weight}` 加权列表，最多 50 条、名字最长 24 字符、权重 0–100；为空时用匿名。
- **立即测试**——立刻随机触发一次，并显示最近一次触发状态（礼物 / 送礼人 / 是否出错）。

触发时的行为：播放绑定素材的特效，并按 `giftTemplate` 叠加一条提示弹幕（`giftShowSender` 控制是否带昵称标签）；并发上限 `giftMaxConcurrent`（默认 2，1–10），超出排队，队列满则丢弃。随机触发**仅在总开关开启且有活跃会话时**参与，空白/无会话页不触发。

## 隐私

- **房间号只存在本地**：`giftRoomId` 仅用于拼 `giftConfig(pc)` 请求，仓库（代码/脚本/CI/文档/测试/截图）里**从不出现真实房间号**，文档示例一律用占位符。
- 目录映射只读白名单字段，原始响应里的房间标识不会外泄；日志只打印数量摘要，不打印房间号。
- 房间号为空时不发起外部请求（见「目录与刷新」）。
- `tools/check-gift-privacy.mjs` 是硬门：默认跑无需秘密的 agent 侧断言；最终门由用户以 `PRIVATE_ROOM_ID=<号码> node tools/check-gift-privacy.mjs` 传入真实号码，要求发布白名单内**零命中**。

## 限制

- **无音效**——特效只有画面，不播放声音。
- **无连击**——目录里的 `combo_id` 仅作为字段保留，没有连击 UI 或连击行为。
- **无移动端**——为桌面 Web 覆盖层设计（Chromium 优先），不做移动端布局。
- SVGA 依赖随包的播放器；素材只做视觉播放，不合成音频。
