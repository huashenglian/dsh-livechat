# 交互

[English](./interaction.md) | [中文](./interaction.zh-CN.md)


所有可触达的部分：浮动控制球、悬停暂停、点击详情、手发弹幕、热度条，以及小庆祝效果。

## 浮动控制球（拖球）

对话区上方有一个可拖动小球（默认右上）。它是常驻快捷控制：

- **拖动**重新定位——位置存 `localStorage`（`dsh-danmaku-ball-pos`），按浏览器持久。
- **点击**弹出快捷菜单：开关弹幕、暂停/继续、打开设置、发消息。
- **空闲**态显小圆点；**活跃**态（近期有触发）显更活泼的弹出。

弹幕完全关闭时拖球隐藏，重新开启时复现。

## 悬停暂停

`hoverPause: true`（默认）时，悬停任意弹幕即冻结便于阅读，移开即恢复滚动。纯客户端，无服务往返，无卡顿。

## 点击详情

点击弹幕打开详情浮层，显示文本与来源徽章：

| 来源徽章 | 含义 |
|---|---|
| 📺 | 预设包 |
| 🤖 | LLM 生成 |
| 💬 | 用户手发 |

浮层内可**复制**文本、**屏蔽**内容（加入 `blockedWords`）、或从会话池**删除**（若是池条目）。

## 手发弹幕

`userSend: true`（默认）在快捷菜单（或拖球）启用文本输入。输入短消息发送——以 `source: 'user'` 飘过，加入会话池，可被历史回放与点赞加权。同样受 `styleMaxChars` / `blockedWords` 约束。

## 热度条

`showHeat: true`（默认）渲染细热度指示，反映当前会话繁忙度。Host 由近期触发计算热度（`/api/danmaku/heat`）：

| 事件 | 分值 |
|---|---|
| `tool_call` | 1.5 |
| `tool_error` | 2.5 |
| `user_message` | 2.0 |
| `reply_complete` | 2.0 |
| `task_done` | 4.0 |
| 其他 | 0.5 |

分值在可配 `window`（默认 30s）上归一为 0–1。高热度让覆盖层亮过空闲透明度；低热度让它暗下来。覆盖层随活动"呼吸"。

## 庆祝与环境效果

绑定事件的小可切花絮：

| 效果 | 配置 | 作用 |
|---|---|---|
| 入场欢迎 | `welcomeOnEnter`（默认 true） | 进入/切换会话时短促欢迎突发 |
| 任务完成刷屏 | `taskDoneRain`（默认 true） | 任务完成时彩纸式弹幕雨 |
| 工具出错吐槽 | `toolErrorSc`（默认 true） | 工具调用出错时吐槽突发 |
| 允许 emoji | `allowEmoji`（默认 true） | 弹幕内容可含 emoji |

## 调试来源徽章

`debugSource: true` 给每条上屏弹幕加来源 emoji 前缀（📺/🤖/💬），调参时一眼看出评论来源。正常使用时关。
